# Gartic Phone Line Drawer v2.4

Gartic Phone 게임에서 그림을 자동으로 그려주는 어시스턴트 프로그램입니다. 사용자가 선택한 이미지를 분석하여 외곽선을 추출하고, 지정된 캔버스 영역에 마우스 입력을 시뮬레이션하여 그림을 그립니다.

## 주요 기능

-   **직관적인 GUI**: `customtkinter`를 사용하여 사용하기 쉬운 그래픽 인터페이스를 제공합니다.
-   **최신 애니메이션/만화 전문 라인아트 AI 모델 6종 지원**:
    -   `AniLines Detail` / `AniLines Basic`: 애니메이션 원화의 세밀한 펜선 및 주요 구조선 추출
    -   `Anime2Sketch`: 스케치 원화풍의 섬세한 표정/눈/머리칼 추출
    -   `AnyLine`: TheMistoAI의 최신 MTEED + Gaussian 디테일 고해상도 엣지 검출
    -   `MangaLineExtraction`: 스크린톤/먹칠을 억제하고 순수 펜터치 구조선 추출
    -   `Lineart Anime`: 만화 전용 고품질 라인아트 모델
-   **외곽선 ➔ 빗금 2단계 순차 분리 드로잉**: 외곽선(구조선) 연산과 빗금 연산을 완전히 분리하여, 이미지의 모든 외곽선이 100% 그려진 뒤에 빗금(해칭)이 그려집니다. 빗금과의 교차로 인한 외곽선 분절을 원천 방지하며, 갈틱폰 제한 시간 내에 확실한 형태를 먼저 완성합니다.
-   **우측 상단 ➔ 좌측 하단 빗금 스윕 엔진**: 빗금 드로잉 시 캔버스 기준 우측 상단(Top-Right)에서 시작하여 좌측 하단(Bottom-Left) 방향으로 순차적으로 채워지는 슬라이딩 윈도우 기반 지그재그(Serpentine) 드로잉을 수행합니다.
-   **적응형 빗금(Hatching) & Cross-Contour(등고선) 엔진**: 채색 면 및 굵은 선의 디테일(눈동자, 글자, 음영)을 보존하기 위해 45°/135° 대각선 빗금, 격자, 거리 변환 기반 3D 등고선 곡선, 명암 적응형 밀도 제어 및 '해칭 없음(외곽선만)' 모드를 지원합니다.
-   **초고속 O(N) 벡터 경로 추출**: 6만 개 이상의 고밀도 빗금 스트로크도 0.05초 이내에 양방향 DFS 최적화 경로로 고속 분할합니다.
-   **다중 레이어 기반 처리**: 여러 AI 모델을 레이어로 구성하여 `합 연산 (Union)`, `오버레이 (Overlay)`, `교집합 (Intersection)` 방식으로 정교하게 합성할 수 있습니다.
-   **미리보기 및 편집**: 자동 그리기를 시작하기 전에 결과물을 미리 보고, 내장된 편집기(연필/지우개)로 선을 수정할 수 있습니다. 상단 정보 바에서 외곽선과 빗금의 개수 및 예상 완료 시간을 실시간으로 확인할 수 있습니다.
-   **설정 저장**: 캔버스 영역, 이미지 경로, 모델 설정, 빗금 옵션 등 모든 옵션을 `line_draw_setting.txt` 파일에 저장하여 재사용할 수 있습니다.
-   **실시간 제어**: `ESC` 키를 눌러 언제든지 그리기 과정을 중지할 수 있으며, GUI 진행률 바에 1단계 외곽선 및 2단계 빗금 진행 상황이 실시간 표시됩니다.

## 파일 구성

-   `run.bat`: 프로그램을 바로 실행할 수 있는 원클릭 실행 배치 파일입니다. (콘솔 창과 함께 실행되어 로그 및 에러 확인 가능)
-   `run_nowindow.bat`: 콘솔 창 없이 백그라운드에서 GUI만 깔끔하게 실행할 수 있는 배치 파일입니다.
-   `line_draw.py`: 메인 애플리케이션 파일입니다. GUI를 생성하고 전체 작업 흐름을 관리합니다.
-   `line_draw_functions.py`: 이미지 처리, 외곽선 검출, 자동 그리기, 설정 저장/로드 등 핵심 로직을 포함하고 있습니다.
-   `hatching_module.py`: 면 빗금 채우기(Hatching), 3D 크로스 컨투어(등고선), 명암 기반 적응형 간격 계산 모듈입니다.
-   `anilines_wrapper.py`: AniLines AI 모델 로더 및 추론 래퍼입니다.
-   `anime2sketch_wrapper.py`: Anime2Sketch AI 모델 로더 및 추론 래퍼입니다.
-   `mangaline_wrapper.py`: MangaLineExtraction AI 모델 로더 및 추론 래퍼입니다.
-   `gartic_phone_canvas.html`: 갈틱폰 캔버스 환경을 가상으로 시뮬레이션한 HTML 테스트벤치입니다. (전체화면, 듀얼 레이어 투명도, 굵기/투명도 넘버박스, 지우개, WebP 저장 등 지원)
-   `line_draw_setting.txt`: 사용자의 모든 설정을 저장하는 텍스트 파일입니다.

## 상세 설정 가이드 (Settings Guide)

프로그램의 주요 옵션들에 대한 상세 설명 및 권장 설정 가이드입니다.

### 1. 조합 방식 (Combination Method)
다중 AI 모델 레이어(L1, L2, ...)를 구성하여 사용할 때, 각 레이어에서 추출된 라인아트/엣지 맵을 합성하는 논리 연산 방식입니다.
- **`합 연산 (Union)`** *(기본값 / 강력 추천)*: 모든 활성 레이어에서 검출된 선을 하나로 합칩니다 (`cv2.bitwise_or`). 예: `AniLines Detail`(세밀한 눈/표정/머릿결)과 `AnyLine`(굵직하고 확실한 외곽 뼈대선)을 결합하여 풍부하고 완성도 높은 선화를 만들 때 가장 효과적입니다.
- **`오버레이 (Overlay)`**: 레이어 순서에 따라 위로 겹쳐서 병합합니다. (기본적으로 합 연산과 동일하게 동작)
- **`교집합 (Intersection)`**: 선택된 모든 레이어에서 공통으로 검출된 선만 남깁니다 (`cv2.bitwise_and`). 배경 노이즈나 지저분한 잔선을 걸러내고 확실한 주선만 추출하고 싶을 때 유용합니다.

### 2. 정밀도 설정 (Precision Setting)
AI 모델로 이미지를 분석하기 전에 리사이징(스케일링)하는 해상도 비율(10% ~ 100%)입니다.
- **`100%`** *(기본값)*: 캔버스 해상도에 1:1로 맞춘 최대 정밀도로 분석하여 원본의 미세한 디테일까지 정밀하게 검출합니다.
- **`50% ~ 70%`**: 분석 해상도를 낮추어 불필요한 미세 잡선이나 텍스처 노이즈를 자연스럽게 완화하고, 생성되는 점과 선의 개수를 줄여 총 그리기 시간을 크게 단축합니다. 갈틱폰 라운드 제한 시간이 촉박할 때 유용합니다.

### 3. Contour 검색 방법 (Contour Retrieval Mode)
OpenCV 기반 외곽선/컨투어 추출 시 계층 구조 탐색 모드입니다.
- **`외곽선만 찾기 (RETR_EXTERNAL)`**: 객체의 가장 바깥쪽 둘레선만 추출하고 내부 구멍이나 내곽선은 무시합니다. 심플한 실루엣 위주의 드로잉에 적합합니다.
- **`모든 선 찾기 (RETR_LIST)`**: 계층 관계(부모-자식) 없이 내부, 외부의 모든 경계선을 평면 리스트로 추출합니다.
- **`모든 선 찾기 + 계층 (RETR_TREE / RETR_CCOMP)`** *(기본값 / 추천)*: 모든 외곽선과 내부 홀(Hole), 포함 관계 계층 트리까지 모두 탐색하여 가장 복잡하고 정교한 구조선을 검출합니다.

### 4. Contour 근사 방법 (Contour Approximation Method)
검출된 외곽선 점 데이터를 선분으로 단순화/압축하는 방식입니다.
- **`선 압축하기 (CHAIN_APPROX_SIMPLE)`** *(기본값 / 추천)*: 수평, 수직, 대각선 방향으로 연속되는 직선 구간의 중간 점들을 제거하고 꼭짓점/끝점만 저장합니다. 점 개수를 획기적으로 줄여 매크로 그리기 속도를 극대화합니다.
- **`모든 점 저장하기 (CHAIN_APPROX_NONE)`**: 엣지 경계상의 모든 픽셀 좌표를 빠짐없이 1:1로 보존합니다. 부드러운 곡선이나 손그림의 유기적인 질감을 왜곡 없이 그대로 표현하고자 할 때 사용합니다.

### 5. Line Epsilon (px)
Douglas-Peucker 알고리즘(`cv2.approxPolyDP`) 기반 다각형 선 단순화(경로 압축) 허용 오차 거리(픽셀 단위)입니다.
- **낮은 값 (`0.5 ~ 1.0 px`)**: 원본 픽셀 경로에 가깝게 매우 정밀하고 세밀한 굴곡까지 모두 보존합니다. 점 개수가 많아져 그리기 시간이 다소 증가합니다.
- **권장값 (`1.5 ~ 2.0 px`)**: 사람 눈에는 원본과 거의 차이가 없으면서 미세한 픽셀 떨림을 직선/완만한 곡선으로 펴주어 점 개수를 30~50% 절약합니다.
- **높은 값 (`3.0 ~ 5.0 px 이상`)**: 선을 과감하게 단순화하여 속도를 극한으로 높이고 미니멀한 카툰 스타일의 선을 만듭니다.

### 6. 선 투명도 / 불투명도 (Line Opacity)
미리보기 및 갈틱폰 캔버스 드로잉에 적용할 펜 선의 불투명도(%)입니다.
- **`100%`** *(기본값)*: 완전 불투명한 짙은 검은색 펜선으로 렌더링합니다.
- **`10% ~ 90%`**: 반투명한 수채화/마커 스타일의 선으로 렌더링하며, 선과 선이 교차하거나 빗금이 중첩되는 영역은 알파 블렌딩(Alpha Blending)되어 자연스럽게 더욱 짙어지는 음영 합성 효과를 미리보기 화면에서 실시간으로 확인할 수 있습니다.

### 7. 초당 마우스 이동 횟수 (Mouse Moves Per Second)
자동 그리기 매크로가 1초 동안 마우스를 이동시키는 최대 빈도(Hz / Polling Rate)입니다.
- **`0 (무제한)`** *(기본값)*: 딜레이 없이 시스템/CPU가 허용하는 최대 속도로 마우스 이동 명령을 즉각 실행합니다. (가장 빠른 그리기 속도)
- **`60 ~ 240`**: 갈틱폰 웹 브라우저의 이벤트 수신 주기(일반적으로 60Hz~144Hz)에 맞추어 마우스 이동 속도를 조절합니다. 마우스 입력이 너무 빨라 브라우저에서 선이 끊기거나 씹히는 현상이 발생할 경우 `120` 또는 `240`으로 설정하면 선이 끊김 없이 안정적으로 그려집니다.

### 8. 면 처리 모드 (Hatching / Surface Shading Mode)
AI 모델이 검출한 굵은 선이나 채색된 넓은 면적(눈동자, 옷 주름, 머리카락 먹칠 영역 등)을 선화로 표현하는 처리 방식입니다.
- **`외곽선 + 빗금 (Outline + Hatching)`** *(기본값 / 추천)*: 면의 바깥쪽 테두리(1px)를 그리고, 내부 채색 면을 만화 스타일의 빗금으로 채웁니다. 가장 입체적이고 완성도 높은 선화가 완성됩니다.
- **`해칭 없음`**: 내부 빗금 채우기 없이 순수한 외곽선만 추출하여 깔끔하고 빠른 선화 드로잉을 원할 때 사용합니다.
- **`순수 빗금 (Hatching Only)`**: 외곽 테두리선 없이 오직 빗금의 밀도와 방향만으로 면과 음영을 묘사하는 에칭/판화 스타일입니다.
- **`스켈레톤화 (Skeletonize)`**: 면의 두께를 1픽셀 중심 뼈대선(골격)으로 축소하여 얇은 단선으로 변환합니다.

### 9. 빗금 패턴 (Hatch Pattern)
면 처리 모드에서 내부를 채울 때 사용하는 빗금 선분의 기하학적 각도 및 패턴입니다.
- **`45° (대각선)`** *(기본값)*: 우상향 45도 방향의 클래식한 만화/스케치 빗금.
- **`135° (역대각선)`**: 좌상향 135도 방향의 반대쪽 대각선 빗금.
- **`0° (수평)`**: 가로 방향의 수평 빗금.
- **`90° (수직)`**: 세로 방향의 수직 빗금.
- **`크로스 빗금 (Cross)`**: 45° 대각선과 135° 역대각선이 X자로 교차하는 정통 크로스해칭(Cross-Hatch) 빗금으로 짙은 음영이나 깊이감 있는 펜화 질감 표현에 최적.
- **`격자 빗금 (Grid)`**: 0° 수평선과 90° 수직선이 +자로 직교하는 바둑판 형태의 격자(Grid) 패턴으로 기하학적이거나 정갈한 음영 표현에 적합.
- **`Cross-Contour (등고선)`**: 물체의 3차원 볼륨을 감싸는 유기적인 동심 등고선 곡선 패턴 (거리 변환 기반 3D 입체감 극대화).
- **`해칭 없음`**: 빗금을 생성하지 않음.

### 10. 적응형 명암 빗금 (Adaptive Shading / Hatching)
원본 이미지의 명도(밝기 및 어두움)에 연동하여 빗금의 간격과 교차 여부를 실시간으로 자동 조절하는 지능형 음영 엔진입니다.
- **체크 활성화 (기본값 / 강력 추천)**:
  - **밝은 영역**: 빗금 간격을 2배 넓게 배치하여 옅은 그림자를 은은하게 표현합니다.
  - **중간 명암**: 사용자가 지정한 기본 간격(예: 8px)으로 균일한 빗금을 배치합니다.
  - **짙은 그림자/먹칠 영역**: 빗금 간격을 1/2로 촘촘히 좁히고, 역방향 보조 교차선(Cross-hatch)을 자동으로 추가하여 흑백 펜만으로 깊고 풍부한 입체 명암을 자동 구현합니다.
- **체크 해제**: 원본 명암과 무관하게 지정된 기본 빗금 간격(px)으로 균일하게 채웁니다.

### 11. 2단계 순차 드로잉 & 우측 상단 ➔ 좌측 하단 빗금 스윕 (Two-Phase Pipeline)
이미지 연산 및 실제 매크로 드로잉 시 **외곽선 단계**와 **빗금 단계**를 완전히 분리하여 실행합니다.
- **1단계 (외곽선 우선 100% 드로잉)**:
  - 캐릭터나 사물의 모든 바깥쪽 테두리선, 눈/코/입, 머리카락 형태 등 주요 뼈대선을 먼저 완벽히 그립니다.
  - 빗금과 외곽선이 교차하면서 테두리가 지저분하게 쪼개지는 버그를 원천 차단합니다.
  - 갈틱폰 라운드 제한 시간이 촉박하여 도중에 그리기가 중단되더라도, 그림의 핵심 외곽선이 이미 완성되어 있어 다른 플레이어가 무엇을 그린 그림인지 즉시 알아볼 수 있습니다.
- **2단계 (우측 상단 ➔ 좌측 하단 빗금 스윕)**:
  - 외곽선이 모두 완성되면 자동으로 빗금 드로잉으로 전환됩니다.
  - 빗금은 **캔버스 우측 상단(Top-Right)**에서 시작하여 **좌측 하단(Bottom-Left)** 방향으로 대각선 스윕하며 규칙적이고 안정적으로 채워집니다.
  - 슬라이딩 윈도우 지그재그(Serpentine) 경로 최적화가 적용되어 마우스가 화면을 가로지르는 불필요한 점프를 최소화합니다.
- **UI 및 진행률 연동**:
  - 편집기(`EditorWindow`) 상단에서 외곽선 개수와 빗금 개수 통계를 분리하여 제공합니다.
  - 매크로 동작 중 GUI 진행률 바에 `1단계 외곽선 (현재/전체)` ➔ `2단계 빗금 (현재/전체)` 상태가 실시간으로 안내됩니다.

## 사용 방법

1.  `run.bat` (또는 `line_draw.py`)을 실행하여 프로그램을 시작합니다.
2.  **[1. 캔버스 영역]** 버튼을 클릭하고 Gartic Phone 게임의 그리기 영역을 마우스로 드래그하여 선택합니다.
3.  **[2. 그림 업로드]** 버튼을 클릭하여 그리고 싶은 이미지를 불러옵니다.
4.  (선택 사항) 정밀도, 모델 레이어, 조합 방식 등 그리기 설정을 조정합니다.
5.  **[3. 미리보기 및 편집]** 버튼을 클릭하면 처리된 이미지의 미리보기가 편집기 창에 나타납니다.
6.  (선택 사항) 편집기에서 연필이나 지우개 도구를 사용하여 선을 추가하거나 제거합니다. 수정이 완료되면 **[진행]** 버튼을 누릅니다.
7.  자동 그리기가 시작됩니다. 그리는 동안 마우스를 움직이지 마세요.
8.  그리기를 중단하고 싶으면 `ESC` 키를 누릅니다.

## 가상 캔버스 테스트 환경 (`gartic_phone_canvas.html`)

갈틱폰에 직접 접속하지 않고도 로컬 환경에서 드로잉 속도, 투명도 블렌딩, 좌표 매핑 등을 실시간 테스트할 수 있는 독립 가상 캔버스 환경을 제공합니다.

- **`run_canvas_kiosk.bat` (강력 추천 / 완전 전체화면)**:
  - Chrome / Edge 브라우저를 **키오스크(Kiosk) 모드** 및 **독립 프로필(`--user-data-dir`)**로 실행합니다.
  - 마우스를 화면 상단(Y=0)으로 이동해도 브라우저 자체의 **'전체화면 종료(X)' 버튼이나 팝업이 100% 차단**됩니다.
  - **외부 링크 간섭 100% 원천 차단**: 일상적으로 사용하는 기본 크롬과 완전히 분리된 독립 프로세스로 구동되어, 다른 앱(카카오톡, 디스코드, 게임 등)에서 웹 링크를 열더라도 캔버스 창이 덮어씌워지지 않고 일반 크롬 창으로만 열립니다.
  - 모니터 0픽셀부터 끝까지 순수한 캔버스로 채워지며, 종료할 때는 `Alt + F4`를 누릅니다.
- **`run_canvas_app.bat` (독립 앱 모드)**:
  - 주소창과 탭이 없는 독립 데스크톱 창 형태로 실행되며, 마찬가지로 독립 프로필로 외부 링크 간섭이 차단됩니다.
- **프로그램 내 `[가상 캔버스 실행]` 버튼**:
  - `line_draw.py`의 **[1. 캔버스 영역]** 옆에 위치한 보라색 버튼을 누르면 원클릭으로 독립 프로필 키오스크 전체화면 가상 캔버스가 즉시 실행됩니다.
- **순수 100% 전체화면 (상단 여백 0px)**:
  - 키오스크 모드에서는 브라우저 자체의 상단 X 팝업이 완전히 차단되므로, 상단 안전 마진 없이 모니터 0픽셀(`Y=0`)부터 화면 끝까지 온전한 100% 가상 캔버스로 동작합니다.
  - **[좌표 복사]** 버튼을 누르면 모니터 전체 영역(`0,0,가로,세로`) 좌표가 즉시 클립보드에 복사됩니다.
- **페이지 이탈 방지 보호 (`beforeunload`)**:
  - 캔버스 내부에 `beforeunload` 보호 리스너가 탑재되어 예기치 않은 새로고침, 뒤로가기, 페이지 닫기 시도시 브라우저 확인 팝업을 띄워 작업 중인 그림 데이터 손실을 방지합니다.
